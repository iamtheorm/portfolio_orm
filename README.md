# Portfolio Website

A classic, minimal portfolio website featuring a modern, clean design with a focus on clarity and professionalism.

## Features

- **Hero Section**: Eye-catching introduction with name, role, and call-to-action buttons
- **About Section**: Personal information and background
- **Skills Section**: Overview of technical skills and technologies
- **Projects Showcase**: Featured projects with descriptions, tech stack, and links
- **Contact Section**: Contact form and social media links
- **Responsive Design**: Optimized for all screen sizes (mobile, tablet, desktop)
- **Accessible**: Built with semantic HTML, ARIA labels, and keyboard navigation support
- **Modern UI**: Clean and professional design with smooth animations

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript
- No external dependencies

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/iamtheorm/portfolio_orm.git
   cd portfolio_orm
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js with http-server
     npx http-server
     ```

3. View the website at `http://localhost:8000` (or the appropriate port)

## Customization

To customize the portfolio for your own use:

1. **Personal Information**: Edit the content in `index.html`:
   - Update name, role, and description in the hero section
   - Modify the about section text
   - Update skills in the skills section
   - Add/modify projects in the projects section
   - Update social media links

2. **Styling**: Modify `styles.css`:
   - Change CSS variables in `:root` to customize colors
   - Adjust spacing, fonts, and other visual elements

3. **Functionality**: Edit `script.js` to add or modify interactive features
